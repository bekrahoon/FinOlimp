## Почему aliases не добавлено (осознанно)

Правило Q3: нет билетного пересечения — нет alias (иначе слияние по голому
имени склеит чужие деньги; деньги движка это переживут — exact+alias, — но
source и флаги «в реестре есть» отравятся).

- 6 «чужих» партий (423 строки): ни одного общего билета с ядром даже по
  хвостам (10 vs 13 знаков проверены оба). Вероятно, корпоративные клиенты /
  другой контур учёта — вопрос партнёру, не правилу. Кандидатов в aliases: 0.
- «Джолдош уулу» (58 строк = все 58 `ambiguous_subset`): строгое
  token-подмножество ровно двух агентов ядра (Эмир + Руслан), общие билеты
  с обоими (65/33). Разделить 58 строк между двумя людьми без построчных
  улик — фабрикация; оставить сиротой принципиально.
