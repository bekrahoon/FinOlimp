# Признаки строки расхождения (P0, `features.csv`: 2165 × 46)

Детерминированы: повторный прогон — байт-в-байт тот же файл
(md5 — см. `test_match_bundle.py`; меняется при изменении движка/`source`).
Привязка к первичным строкам — через `parse.load_data`
(хвосты билетов / txn_id / ЦБ-С), фильтр той же стороны — как компоненты движка.

## Деньги (8)
- `sum_1c`, `sum_etm`, `diff`, `abs_diff` — как в `discrepancies.csv`.
- `rel_drift` = |diff| / max(|sum_1c|, |sum_etm|) — относительный дрейф.
- `one_sided_1c` / `one_sided_etm` — вторая сторона нулевая (порог 0.01).
- `round_1k` / `round_9k` / `round_10k` / `round_36k` — |diff| ровно круглый
  (подписи опечаток/удержаний из разборки: 1000/9000/10000/36000).
- `pct_5` / `pct_10` — |diff|/|sum_1c| ровно 5% / 10% (подпись ETM-занижений).

## Время (4)
- `age_days` — возраст от конца выгрузки (max дата данных, `auto`); `fresh_31d` — щит timing:
  свежее 31 дня сначала считается лагом, не ошибкой.
- `month`, `month_edge` — месяц и близость к границе месяца (±3 дня; акты месячные).

## Класс и состав (6)
- `source`, `prefix` — источник и шаблон комментария движка (Шаг 4).
- `n_tickets` — билетов в идентификаторе; `n_authors` — авторов в суффиксе
  `(реестр: …)`; `in_registry` — флаг «в реестре есть» (после v2-привязки).

## Сторона ETM (9)
- `n_etm_rows`, `creator_bot` / `creator_sub` / `creator_mixed` / `creator_none`.
- `kind_выкуп` / `kind_возврат` / `kind_войд` / `kind_оплата` — виды проводок компоненты.

## Сверка с реестром, v2-правило как признаки (5 + 4 conv)
- `n_reg_rows` — привязанных строк реестра; `reg_parseable` — все KGS-парсабельны.
- `reg_sum` — сумма KGS-сумм (база + сборы); `reg_eq_1c` / `reg_eq_etm` — совпадение
  с точностью 0.01. Парсинг строгий: только KGS-чанки (`sf` — маркер сбора, не валюта;
  скобочные пометки с буквами вычищаются); валютные строки → NaN.
- Q2-конверсия: `reg_parseable_conv` / `reg_sum_conv` / `reg_eq_1c_conv` /
  `reg_eq_etm_conv` — все валюты через курсы строки (`P.parse_pay_kgs_total`,
  якоря S110/S112/S119: S112 — в копейку; S110 +0.11, S119 +0.19 из-за округления
  курсов до 2 знаков). Точность сравнения — CONV_TOL 2.0 (ошибка округления ≤
  0.005 × сумма; проверено вручную на 10 строках × 5 валют). Покрытие: 403 → 1373.
  Голые номера билетов без валюты → NaN (у строки нет суммы, честно).
- `short_party` — партия короче имени агента (был subset-merge): маркер naming gap.
- Ограничение: много-билетная запись реестра целиком относится на каждую
  одно-билетную компоненту с её хвостом (завышение `reg_sum`, консервативно —
  равенств меньше, не больше).

## История агента без утечек (2)
- `agent_prior_n`, `agent_prior_money` — строго prior-to-row (дата < даты строки):
  сколько расхождений/денег у агента было до этой строки.

## Что НЕ признак (осознанно)
- Сам текст `comment` (утечка метки), будущие строки агента,absolute-пороговая
  бинаризация без протокола. Absolute-суммы агента — только через prior-агрегаты.
